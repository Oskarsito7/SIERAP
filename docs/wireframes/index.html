SIERAP · Diseño de GUI · Momento 1

Wireframes de SIERAP

Pantallas de media fidelidad para los cinco roles del sistema, en escala de grises y con componentes al estilo shadcn/ui (ADR-006), para que el equipo las implemente casi tal cual. Siguen las decisiones de docs/04 y el contrato de la API de docs/07. Los datos son de ejemplo, con el Momento 1 real de Ingeniería de Sistemas (5 RAP, 8 criterios, máximo 5,00).

Cómo leerlos

  • Cada pantalla tiene un código (DO-05), los requerimientos y la etapa que la cubren, y las reglas que el frontend debe respetar.
  • El menú lateral de cada rol es el aprobado el 27/09/2026 (docs/06). Las opciones sin página todavía muestran AU-07.
  • Estados: fondo oscuro para lo activo o abierto; borde simple para lo neutro o cerrado; borde punteado para lo que requiere atención (tardío, bajo el mínimo, pendiente).
  • Las imágenes para el documento de entrega se generan con docs/wireframes/export-png.cjs.
